# Quizzes rc.28 — selectable screen styles

The host chooses independently from 12 host and 8 projector styles inspired by the supplied sample images, or retains the current look. A thumbnail helps identify each reference. The styles are functional adaptations, not pixel-perfect reproductions: real question text, images, timers and controls remain live. The user's image is fitted without cropping. The projector updates immediately, including across devices; only the host can change a style. The style pair is retained for recovery of the same live room; a new room starts with the default look.

Voting badges, round announcement, final podium, buzzer behavior and phone layout remain. During an open question, the host's answer count is hidden; connected-player count remains visible. No database schema changes and no changes to stored quizzes, publications, attempts, reports or scores. Deployment restarts the service, so update between games.
