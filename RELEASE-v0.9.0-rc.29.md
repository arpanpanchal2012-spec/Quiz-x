# Quizzes rc.29

The rc.28 selectors changed mostly colors and did not provide the visual difference promised by the samples. This update adds distinct framed-studio, panorama, light and neon image-question layout families to the desktop host and projector screens. Depending on the selected style, the live question plate, image frame, spacing, lighting and placement change. Each reference is an inspiration rather than a pixel-perfect copy. The existing quiz image is shown without cropping. Non-image questions, result screens, phone layout, timings, scoring and controls retain their established behavior. The original rc.28 selection controls and 12 host and 8 projector options remain.

No database migration, and no changes to stored quizzes, publications, attempts, reports or scores. Live room styles continue to survive room recovery.
